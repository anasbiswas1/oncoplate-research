# Baselines, implementation choices and remaining scientific decisions

## Implemented controlled principal comparison

M2: same joint-record candidate, confidence transformed using the independently rated calibration split.
M3: generic learned support selector, no source gate.
M6: deterministic source eligibility with the calibrated candidate-confidence score; no learned provenance selector.
M7: source eligibility plus the matched learned provenance-aware selector.

These four use the same one-focal-claim candidate and the same available inputs. Fitting uses OOF predictions. Main candidate/selector features use raw predictor probabilities consistently in OOF and deployment; support scores are calibrated separately. Attribute calibration is a separate reported experiment. The principal regularised logistic contrast is supplemented by a fixed small MLP capacity ablation.

M0 frequency prediction and deterministic documentary information are available. Independent heads provide the M1 foundation. A broader field/family claim can be generated by a separately registered focal rule for hierarchical selective comparison; it needs independent ratings and cannot inherit the original fine-grained label. The finite gate can select recorded versus predicted wording, but this package does not claim an exact reproduction of a published hierarchical selector.

M5 is an explicitly optional **group-max binary-support prediction-set adaptation**, not the full ConfLVLM/IntroConformal algorithm or its guarantee. Group-marginal coverage does not give error control conditional on selecting only supported-singleton sets. No first-ever or clinical certificate is asserted.

M8 one-action replay uses actual documented answers and equal menus/budgets. Its before/after claim outputs need independent review. End-to-end prospective user behaviour and response mistakes must still be measured.

M9 is a reference-informed upper bound only. It is not routed through deployable inference code. When reported, construct it during post-lock evaluation and label it explicitly; never supply it to the learned selector.

## Recognition and VLM comparisons

Three fixed families: TorchVision ResNet-50 IMAGENET1K_V2; TorchVision ConvNeXt-Tiny IMAGENET1K_V1; HF facebook/dinov2-small (DINOv2 ViT-S/14). This is not ConvNeXt-V2. Full-frame letterbox preprocessing is a deliberate documented deviation from classification centre crops. No object-removing augmentation is applied by default.

Local Qwen2.5-VL-7B-Instruct and SmolVLM-Instruct adapters are supplied, with immutable revision resolution at first authorised execution. Direct and staged recognition are included. They are **controlled reimplementations/adaptations**, not benchmark-fidelity reproductions of FoodCHA or other papers. Full published-protocol reproduction, a more advanced multimodal fusion network, a learned focal detector and additional constrained decoding remain possible research extensions, not completed results.

For new data, the joint head includes complete category/subcategory/method tuples and supplementary atomic animal-source/processing/surface outputs where those independently annotated fields exist. This multitask implementation choice must be retained in the model description. The complete-record vocabulary is not the full Cartesian product of food and methods.

## Candidate and reference boundary

The implemented multimodal candidate generator uses visual predictions and explicit documentary late fusion. It is not claimed to be a trained cross-attention model. PCSI preserves unknown alternatives for missing focal attributes and uses a finite reviewed source predicate. Its universal condition applies to the represented focal states; unmodelled alternatives and incomplete reference data remain limitations.

The default `joint_marginal_gap` is zero unless actual paired predictor scores are supplied. Do not claim a pairing-gap ablation from an all-zero feature. The scripts and contracts support a field derived from independent/joint OOF predictions; train both partners within the same held-group exclusions before including it. A whole-meal presence model does not localise arbitrary items. Use the explicit focal-input contract.

Some late notebooks require actual independent human reviews, collection data or assay results. They do not generate those references from model predictions. Data sufficiency, expert review, power/precision justification, exact permitted claim wording and clinical/product validation are not solved by more GPU runs.
